# femtic_crossplot.py

Crossplots (scatter) of observed vs. calculated data from a FEMTIC
`results_iterN.h5` file, one panel per data type and component, with
log10(frequency) encoded as point colour.

- Author: vrath (DIAS), py4mt
- Code generated by Claude Sonnet 5 (Anthropic), 2026-09-18 -- AI-generated,
  review before production use.

## Overview

- Reads `/data` via `femtic.read_results_data()` (observed = `re_val`/`im_val`,
  calculated = `cal_re`/`cal_im`, observed errors = `re_err`/`im_err`).
- Groups rows by `datatype_name` / `component_name`.
- Complex data types (MT, HTF, VTF, NMT, NMT2, ...): one Re and one Im panel
  per component. Real data types (APP_RES_AND_PHS, NMT2_APP_RES_AND_PHS, PT):
  one panel per component.
- One figure per data type, written to `OUT_DIR` in every format in
  `PLOT_FORMATS`, named `<prefix>_<DATATYPE>.<ext>`.
- Per-panel statistics (n, dropped rows, rms, nRMS) printed and written to
  `<prefix>_stats.txt`.

## Usage

    python femtic_crossplot.py                      # RESULTS_FILES from config
    python femtic_crossplot.py results_iter12.h5    # file(s) on command line

`femtic.py` (and `ensembles.py`, which it imports) must be importable;
if `PY4MTX_ROOT` is set, `$PY4MTX_ROOT/py4mt/modules` and `.../scripts` are
added to `sys.path`.

## Configuration (uppercase block at the top of the script)

| Name | Default | Meaning |
|------|---------|---------|
| `RESULTS_FILES` | `["results_iter10.h5"]` | Input files (overridden by argv) |
| `OUT_DIR` | `./crossplots/` | Output directory |
| `OUT_PREFIX` | `None` | File prefix; `None` -> stem of the input file |
| `PLOT_FORMATS` | `(".png", ".pdf")` | Output formats |
| `PLOT_DPI` | `300` | Raster resolution |
| `DATATYPES` | `None` | Restrict to these data type names |
| `COMPONENTS` | `None` | Restrict to these component names |
| `NCOLS` | `4` | Panels per row |
| `PANEL_SIZE` | `3.3` | Inches per panel edge |
| `EQUAL_ASPECT` | `True` | Square panels, 1:1 line at 45 degrees |
| `CMAP` | `"turbo"` | Colormap for log10(f) |
| `COLOR_RANGE` | `"global"` | `"global"`: common log10(f) range; `"panel"`: per panel |
| `MARKER_SIZE`, `ALPHA` | `14.0`, `0.85` | Scatter appearance |
| `LOG_RHO` | `True` | Log-log axes for `rho*` components (if all values > 0) |
| `SHOW_ERRORBARS` | `False` | Horizontal error bars from observed errors |
| `SHOW` | `False` | Interactive display |
| `WRITE_STATS` | `True` | Write statistics table |

## Notes

- Rows with non-finite observed/calculated value or frequency are dropped per
  panel; the count is reported in the statistics table (this includes rows
  counted in `nMissingCalc`).
- nRMS = sqrt(mean(((obs - calc) / err)^2)) over rows with finite, positive
  error.
- Pre-2026-09-13 `data_iterX.h5` files have no `cal_re`/`cal_im`;
  `read_results_data()` raises `KeyError` for them, so no crossplot is possible.
- Axis units are not annotated: they follow whatever FEMTIC wrote to the file.
